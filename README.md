# Sazón — demo de gestión gastronómica

Aplicación demo para una casa de comidas, construida con Next.js, React y TypeScript.

## Requisitos

- Node.js 20.9 o posterior
- npm

## Ejecutar

```bash
npm install
npm run dev
```

Abrí http://localhost:3000.

## Validar compilación

```bash
npm run build
npm start
```

## Funcionalidad

Incluye inicio, pedidos, cocina, menú digital, stock, compras, caja, facturación simulada y reportes. Los datos se guardan localmente en el navegador.

La facturación no genera comprobantes fiscales ni se conecta con AFIP/ARCA.
