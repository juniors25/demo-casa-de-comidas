## Si aparece un aviso de hidratación

La página del menú QR se monta en el navegador para evitar diferencias entre el HTML del servidor y el código QR generado con la URL local. Si el aviso menciona `monica-id` o `monica-version`, lo inyecta la extensión de navegador Monica, no la aplicación: probá en una ventana de incógnito o desactivá esa extensión para el sitio.
