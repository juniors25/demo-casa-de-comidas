# Sazón — demo de gestión gastronómica

Aplicación demo para una casa de comidas, construida con Next.js, React, TypeScript y Tailwind CSS.

## Requisitos

- Node.js 20.9 o posterior
- npm

## Ejecutar en Windows

Abrí PowerShell o CMD en la carpeta del proyecto y ejecutá cada comando por separado:

```bash
npm install
npm run dev
```

Luego visitá http://localhost:3000.

## Validar compilación

```bash
npm run build
npm start
```

Incluye inicio, pedidos, cocina, menú digital, stock, compras, caja, facturación simulada y reportes. Los datos se guardan localmente en el navegador.

La facturación es exclusivamente demostrativa; no genera comprobantes fiscales ni se conecta con AFIP/ARCA.
